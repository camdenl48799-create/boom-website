# B.O.O.M. Setup Wizard

The setup wizard lives at `/setup.html` in the Vite app.

## Flow

1. Welcome
2. Creator profile
3. First project and target platform
4. Theme and cloud preferences
5. Ready screen

Preferences are saved locally in the browser under `boom-setup` so the wizard can remember the setup between visits.

## Design goals

- Fast, focused onboarding
- Dark B.O.O.M. visual language
- PC + VR as a first-class target
- No pricing or checkout flow
- Easy to replace local persistence with a real account/cloud service later
